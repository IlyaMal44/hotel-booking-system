# common

Библиотека, не сервис. Её используют остальные модули.

- `ErrorDto` и `ErrorResponses` — один формат ошибки
- `JwtKeys` — HMAC-ключ не короче 32 байт
- `DateRanges` — правила интервала проживания
- `DemoStay` — общие даты демо-брони, чтобы две базы описывали один и тот же заезд
- `Traces` — имена заголовков корреляции
